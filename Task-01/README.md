## 📱 Project Overview

The Catchhub landing page showcases key features of the Catchhub social networking and media mobile app:
- **Hero Section**: Catchhub signature branding, core value proposition (*"WATCH. COMMUNICATE. CREATE."*), and downloadable store buttons for Android and Apple App Store.
- **Channels Section**: 3D angled smartphone mockup presenting video playback, subscribers, and community channels.
- **Messages Section**: Highlighting seamless communication and social/professional group chats with clean mobile preview.
- **In Future Section**: Categorized service explorer with custom category iconography (*Foods, Events, Party, Metro, Jobs, Housing, Places*) and event booking card views.
- **Footer / Call-to-Action**: Centralized download trigger, interactive contact support link, and Peratude branding emblem.

---

## 🛠️ Built With

- **HTML5**: Semantic elements (`<header>`, `<main>`, `<section>`, `<footer>`, `<figure>`, `<picture>`).
- **CSS3**: Custom properties, Flexbox, CSS Grid, media queries, SVG shape dividers, drop shadows, and fluid scaling with `clamp()`.
- **Typography**: Google Fonts (*Montserrat* & *Open Sans*).
- **Icons**: Hand-crafted crisp SVG icons for Android & Apple badges.

---

## 📐 Responsive Breakpoints

- **Desktop (>= 1200px)**: 1:1 pixel-accurate layout corresponding to the 1920px reference canvas.
- **Tablets (601px - 1199px)**: Balanced column wrapping and centered content hierarchy.
- **Mobile (<= 600px)**: Single-column vertical layout with touch-friendly store buttons and optimized typography.
