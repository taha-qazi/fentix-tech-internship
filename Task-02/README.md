# Task 02: Catalog-Z Clone

## 📝 Overview
This folder contains the solution for **Task 02** of the Fentix Tech Web Development Internship. The objective was to create a pixel-perfect clone of the "Catalog-Z" template website.

## 🛠️ Technologies Used
- HTML5
- CSS3
- Flexbox (for layout and positioning)

## 🎯 Key Achievements
- **Pixel-Perfect Accuracy:** Closely matched the original design, including precise spacing, alignment, colors, and typography.
- **Pure Flexbox Layout:** Recreated the complex multi-column responsive image gallery and navigation bar relying solely on CSS Flexbox, without using external CSS frameworks or JavaScript.
- **Hover Effects:** Successfully implemented the interactive `effect-ming` image overlay hover animations using pure CSS.
- **Asset Management:** Programmatically downloaded and structured all image assets locally.
